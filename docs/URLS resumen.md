## 📝 Notas Importantes

### URLs Nuevas vs Legacy
- Las **URLs nuevas** son más descriptivas y fáciles de identificar para compartir en clases
- Las **URLs legacy** siguen funcionando para mantener compatibilidad con links antiguos
- Ambas URLs apuntan al mismo formulario

### Para compartir en clases
Se recomienda usar las **URLs nuevas** ya que son auto-descriptivas:
- `/recurso-gratuito-negocios` en lugar de `/admin`
- `/recurso-gratuito-negocios-paso1` en lugar de `/paso1`
- `/recurso-gratuito-negocios-paso2` en lugar de `/paso2`
- `/recurso-gratuito-os` en lugar de `/operaciones-saludables`

### IDs en Base de Datos
Los IDs en la base de datos NO cambiaron:
- `diagnostico_paso1` → Recurso gratuito negocios – Paso 1
- `diagnostico_paso2` → Recurso gratuito negocios – Paso 2
- `operaciones_saludables` → Recurso gratuito OS
